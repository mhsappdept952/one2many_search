ONE2MANY LINE SEARCH

Find the right line in seconds

Add a focused, native-looking search experience to configured One2many lists. Choose the searchable fields once, then let users filter long documents without scrolling through every line.

Search that fits naturally into Odoo

One2many Search works on the lines of the record already open on screen. It filters the displayed list only; it does not delete, reorder, or replace the underlying relation.

1

Configure per list

Select the parent model, its One2many field, and the direct line fields users should be able to search.

2

Choose, then search

Typing opens familiar field suggestions. The list is filtered only after the user selects a search option.

3

Keep Odoo security

Results continue to respect the current user's field access, model access rights, and record rules.

ADMINISTRATOR SETUP

Configure it once

Open the configuration from the Technical menu and connect the module to any supported One2many list.

Settings → Technical → Database Structure → One2many Search
  1. Create a new configuration.
  2. Select the Parent Model, such as Sales Order.
  3. Select its One2many Field, such as Order Lines.
  4. Choose the stored Searchable Fields from the line model.
  5. Optionally use Use Visible List Columns to populate suitable fields from the list view.
  6. Save the configuration and refresh the target form.

DAILY USE

A familiar three-step search

1

Enter a value

Type a product, reference, date, quantity, or another configured value.

2

Select the field

Choose one field or search across all configured fields from the suggestions.

3

Review matching lines

The current list shows only matches. Clear the search to restore every line.

Predictable matching for every field

Field type Matching behavior
Text and selection Case-insensitive partial matching.
Integer, float, monetary Exact numeric matching, so searching for 0 returns only zero values.
Many2one and reference Matches the Odoo display name, including an internal reference when present.
Date and datetime Matches the value supplied through the selected search option.

Safe by design

Searches are limited to lines belonging to the open parent record and are executed with the current user's permissions.

Lightweight setup

No changes are required in every business form. Configure supported lists centrally from the Technical menu.
